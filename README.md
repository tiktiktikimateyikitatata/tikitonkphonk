# Digital ID Prototype v3

iPhone-first full-screen web app prototype.

Changes in v3:
- No simulated phone frame.
- No app lock/password on startup.
- Splash screen appears first and can use an imported image.
- Orange/maroon gradient visual system.
- Refined typography, spacing and icons.
- Solid/filled Home icon in bottom navigation.
- Scan QR is now a QR display page, not a camera scanner.
- QR regenerates every 15 seconds with synthetic prototype session data.
- Dedicated Share Driver Licence page.
- Persistent editable developer settings behind long-press + developer PIN.
- Settings items link to https://www.qld.gov.au/digital-identity.
- Driver licence page has no second/motorcycle class.
